# Security and Responsible Use

This repository provides offline verification material for experiments
conducted on author-owned equipment in a controlled RF test bench. It contains
no flashable active firmware, hardware campaign runner, binding phrase, or RF
transmission tool.

Use the material only on equipment and RF environments for which you have
explicit authorization. Do not use it to interfere with third-party links,
aircraft, vehicles, or safety-critical systems.

To report an accidental disclosure, integrity problem, or unsafe repository
content, contact the corresponding author privately at
`melik.e.lemariey@pm.me`. Do not include third-party secrets, unauthorized RF
captures, or operational target data in a public issue.
